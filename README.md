# Student Placement Prediction & Analytics Project

This project predicts the placement chances of students using Machine Learning. 
It provides an interactive dashboard to input student details and get predictions.

## Features
- Data Analysis and Visualization
- Predict Placement using Logistic Regression
- Interactive Streamlit Dashboard
- Optional MySQL Integration
- Easy to extend with more ML models

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit
